## 05. Local Development Setup

### Prerequisites
- Node.js (v18+ or v20+)
- pnpm (or npm / yarn)

```bash
# Clone the repository
git clone https://github.com/Gitika-27/Portfolio.git
cd Portfolio

# Install dependencies
pnpm install

# Start local development server
pnpm run dev
# Server will launch at http://localhost:3000/

# Build for production
pnpm run build

# Preview production build locally
pnpm run preview
# Preview server runs at http://localhost:4173/
```

## 06. Deployment to Vercel

The project is pre-configured with `vercel.json` for zero-configuration, production-grade deployment on Vercel:

1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: complete editorial personal portfolio"
   git remote add origin https://github.com/Gitika-27/portfolio.git
   git push -u origin main
   ```
2. Navigate to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import the `portfolio` repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**.
